# 侧边备忘录 (side-memo)

贴在屏幕边缘、鼠标滑出即用的桌面便签工具。Tauri 2 构建，安装包 ~3MB，数据纯本地。
**备忘**（随手一句）+ **笔记**（成段内容，可内嵌图片、Markdown）双模式，支持外观深度自定义。

## 功能

### 贴边与快捷键

- **左右吸边可选**：设置里一键切换面板吸屏幕左缘还是右缘（双屏建议吸外侧）
- **收起状态三档**：描述标签（竖排文字）/ 把手细条 / 完全隐藏；贴边宽度 8–48px 可调，
  收起后边条里只显示把手或标签，不露正文
- **收起延迟可调**：鼠标离开且失焦后 0–10 秒自动收回（默认 0.9 秒，可固定不收）
- **双屏安全**：用窗口区域（SetWindowRgn）裁剪实现收起与滑动，窗口任何时刻都不会
  越过屏幕边缘——贴在两块屏的接缝上也绝不遮挡相邻显示器，被裁掉的部分不渲染、不拦鼠标；
  鼠标在哪块屏的边缘悬停，面板就滑出到哪块屏
- **全局快捷键** `Ctrl+Alt+M`（可改，支持 Ctrl/Alt/Shift + 字母/数字/F1-12/方向键/空格）：
  任何界面唤出 / 隐藏；`Esc` 收起；单实例运行，重复启动唤出已有面板
- 快捷键被其他程序占用时不再闪退，托盘和面板仍可用

### 备忘与笔记

- **备忘**：Enter 保存、双击编辑、置顶、完成打勾、搜索、清除已完成；超 6 行自动折叠
- **笔记**：标题 + 正文编辑器，输入自动保存；列表按「置顶 / 今天 / 昨天 / 本周 / 本月 / 更早」
  自动分组；正文写 `#标签` 自动归类并支持点击筛选；不常用的可归档
- **插图**：编辑器内直接粘贴截图或选文件（≤15MB），点击放大预览；未引用图片 1 小时后自动清理
- **Markdown 预览**：标题/加粗/斜体/删除线/行内代码/围栏代码块/引用/有序无序列表/
  任务清单/分隔线/链接（系统浏览器打开）
- **提醒**：备忘上 🔔 设定时（10 分钟 / 1 小时 / 明早 9 点 / 明天此时 / 自定义），
  到点弹系统通知并自动滑出面板（不抢焦点），错过的时间点启动后补发

### 外观

- **风格预设**：跟随主题 / 海洋 / 暗夜 / 暗夜紫 / 奶油 / 青瓷 / 雾蓝 / 壁纸毛玻璃，一键打包
  背景色 + 不透明度 + 模糊 + 压暗
- **不透明度**：20%–100%，调低后透出桌面，配合亚克力毛玻璃效果
- **背景色**：8 个预设色板 + 自定义取色器；**背景图**：任选图片铺满面板
- **背景图模糊**：开关 + 2–30px 磨砂；**背景图压暗**：0–80%，亮壁纸不晃眼
- **强调色**：7 个预设 + 取色器，按钮 / 开关 / 把手 / 标签全跟随；**正文字号** 12–18px
- 深色 / 浅色主题一键切换

### 数据与系统

- 本地存储 `%APPDATA%\com.zcode.sideMemo\memos.json`，纯本地无网络，旧版本数据自动兼容
- 自动备份：每次修改留档（10 分钟内不重复），保留最近 10 份，可一键打开备份目录
- 系统托盘：左键唤出/隐藏，右键菜单开机自启 / 退出；托盘悬停显示版本号（设置页底部同）

## 安装

- 系统要求：Windows 10/11 x64，WebView2 运行时（安装包已内嵌引导器；离线环境建议先装
  [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)）
- 安装包未签名，SmartScreen 弹窗时点「更多信息 → 仍要运行」

## 开发 / 构建

```powershell
# 前端是 ui/ 下的静态文件（无 Node 依赖），改完重新编译即生效
cd src-tauri
cargo build                # 调试构建
cargo build --release      # 发布构建，产物在 target\release\side-memo.exe
cargo install tauri-cli    # 打安装包需要（一次性）
cargo tauri build          # NSIS 安装包，输出在 target\release\bundle\nsis\
```

## 目录结构

```
ui/                       前端（纯 HTML/CSS/JS，编译时嵌入二进制）
src-tauri/src/main.rs     存储、提醒、托盘、全局快捷键
src-tauri/src/dock.rs     贴边停靠（左右吸边、区域裁剪、收起/展开动画）
scripts/                  环境、图标、测试辅助脚本
```

## 调参

收起把手宽度范围、触发区、动画步长等常量在 `src-tauri/src/dock.rs` 顶部；
面板默认宽度 `PANEL_DEFAULT_WIDTH`（340 逻辑像素）；失焦收回延迟默认值 `DEFAULT_RETRACT_MS`（900ms）。

## 已知限制 / 后续方向

- 提醒依赖应用处于运行状态（含托盘常驻）
- 无多端同步（计划支持 WebDAV；同步需连 `images/` 目录一起）
- Markdown 为手写渲染器的常用子集，表格等语法暂不支持
- 笔记图片不支持拖拽文件插入
- 安装包未签名，首次安装 SmartScreen 可能提示
